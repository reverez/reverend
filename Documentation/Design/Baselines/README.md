# Development Baseline Records

This directory stores execution evidence used to start and validate Cloud Development.

The historical accepted Reverend 0.4.0 baseline remains:

- docs/current/release/final-acceptance.md
- revision 418524b533f6c05587698dffe8b9a5e4f0434093
- 619 passed / 0 failed
- full live final validation accepted

That historical result must not be presented as the current-main test count.

Before C0, copy baseline-record-template.md to a dated file and record a fresh run from current main.

Suggested filename:

~~~text
YYYY-MM-DD-c0-entry-baseline.md
~~~

Baseline records are evidence, not architecture authority.
