# Wave 2 — Stakeholder / Product MVP

Pipeline:
Evidence → Stakeholder Resolver → synthetic stakeholder findings → expert/evidence audit → simplification/conflict detection → Product Strategy.

Hard provenance rule:
- synthetic stakeholder findings are always `SIMULATED`;
- they cannot create evidence;
- Product Strategy records evidence references separately from stakeholder simulation IDs;
- Product output remains `GENERATED`.

`ProductDecisionPack` contains requirements, non-goals, scope, priorities, trade-offs, success criteria and a validation plan. Raw stakeholder requests do not flow directly to Development Intelligence.
